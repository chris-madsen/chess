# Change: local-style-engine-lines

## Summary

Add a local `StylePath` CLI mode that replaces public Lichess bot probes for the first implementation path. The CLI builds mixed-source teaching lines from self-hosted style engines and Maia 1900: odd plies are generated by one local style engine, even plies are generated by Maia.

## Motivation

LeelaAlien and Boris-Trapsky challenges are controlled by external bot policy and are not reliable as a default analysis source. The trainer needs deterministic, locally reproducible idea generation that keeps move legality and provenance explicit.

## Scope

- Add local style-engine source semantics for Patricia, Jackal, and Seer.
- Add a `StylePath` generator and CLI for FEN and RAW SAN game files.
- Keep Maia 1900 as the opponent-response provider.
- Add UCI process adapters behind application ports.
- Add local install/verification scripts for enabled local style engines.

## Out of scope

- Stockfish 19 continuation in this CLI mode.
- Lichess challenge probes in this CLI mode.
- CSTal runtime integration until a supported Wine or Linux runtime is configured.
- UI beyond terminal output.
