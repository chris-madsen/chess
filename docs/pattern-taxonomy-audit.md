# Pattern Taxonomy Audit

The catalog distinguishes a static mating geometry from a mating combination.
`MATE_GEOMETRY` is scored from the current king-relative position. `MATING_SEQUENCE`
and `HYBRID` also have a bounded trajectory descriptor when the caller supplies
history. The trajectory layer describes pattern identity only; Tal remains the
tactical soundness gate.
